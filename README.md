# inhCHAT

Локальный веб-клиент для LLM с обычным чатом и автономным **«Режимом работы»**.

## Что есть

- Flask backend на `127.0.0.1:6767`.
- HTML/CSS/JS без тяжёлого frontend-фреймворка.
- Один или несколько локальных пользователей, управляемых серверным `users.json`.
- История чатов в SQLite.
- Подключение произвольных OpenAI-compatible API из окна настроек: URL, модель и ключ.
- FreeDeepseekAPI автоматически устанавливается в `.vendor/`, отдельно скачивать его репозиторий не нужно.
- Вход в DeepSeek запускается из настроек inhCHAT.
- Обычный режим чата.
- Автономный «Режим работы» с tool calling и файловым workspace.

## Пользователи

Регистрация из интерфейса намеренно удалена. Пользователи задаются только на сервере в `users.json`.

После `./setup.sh` файл создаётся автоматически:

```json
[
  {
    "username": "admin",
    "password": "676769"
  }
]
```

Чтобы добавить пользователя, отредактируй `users.json`, например:

```json
[
  {"username": "admin", "password": "676769"},
  {"username": "test", "password": "another-password"}
]
```

Изменение пароля или добавление пользователя применяется при следующем входе. Файл является источником истины: пользователь, удалённый из `users.json`, больше не сможет войти, а его активная сессия будет отклонена следующим защищённым запросом.

`users.json` не попадает в Git и автоматически получает права `600`. Пароли в нём хранятся в открытом виде только потому, что это локальный административный конфиг. Если сервер когда-нибудь будет вынесен за пределы личного Mac, такую схему нужно заменить на отдельное безопасное хранилище секретов.

## Архитектура

```text
Browser
   │
   ▼
inhCHAT UI (HTML/CSS/JS)
   │ HTTP
   ▼
Flask :6767 (обычный пользователь macOS, без sudo)
   ├── users.json → управление доступными аккаунтами
   ├── SQLite → чаты / провайдеры / хэши паролей
   ├── LLM adapter → OpenAI-compatible APIs
   ├── Work Mode agent loop + tools
   └── DeepSeek control
          │
          ▼
   FreeDeepseekAPI :9655
```

Порт `6767` выбран специально: это обычный непривилегированный TCP-порт, поэтому Flask не требует `sudo`. Это устраняет прежнюю проблему с `Permission denied` на порту `698`.

## Полный запуск на macOS

Нужны Git, Python 3 и Node.js 18+.

```bash
cd ~/Desktop
# если репозиторий уже клонирован, используй только cd в него
cd inhChatWorkLLM
git pull --ff-only origin main
chmod +x setup.sh start.sh
./setup.sh
source .venv/bin/activate
./start.sh
```

После запуска открой:

```text
http://127.0.0.1:6767
```

Логин по умолчанию: `admin`  
Пароль по умолчанию: `676769`

Первый запуск автоматически:

1. создаёт Python virtualenv;
2. устанавливает зависимости;
3. скачивает FreeDeepseekAPI внутрь `.vendor/`;
4. устанавливает npm-зависимости;
5. создаёт `.env`;
6. создаёт `users.json`;
7. подготавливает SQLite и `workspace/`.

## DeepSeek

В inhCHAT открой `⚙ Настройки` → `DeepSeek` → `Войти в DeepSeek`. После успешной авторизации следующий запуск `./start.sh` автоматически поднимает FreeDeepseekAPI на `127.0.0.1:9655`.

## Провайдеры

В `⚙ Настройки` → `Провайдеры` можно добавить любой совместимый endpoint:

```text
Название: OpenAI
Base URL: https://api.openai.com/v1
Model: <нужная модель>
API key: <ключ>
```

Ключи остаются в локальной SQLite-базе и не отправляются в Git.

## Режим работы

Переключатель `◉ Режим работы` включает автономный агентный цикл. Доступны:

- `calculator`;
- `list_workspace`;
- `read_file`;
- `write_file`.

Файловые операции ограничены `workspace/`. Лимит автономного цикла: 12 шагов на запрос.

## Безопасность

- `.env`, `users.json`, база, логи, workspace и vendor-копия исключены из Git.
- Пароли после загрузки из `users.json` хранятся в SQLite как хэши.
- API-ключи предназначены для локального использования.
- Не публикуй `deepseek-auth.json`, поскольку это credential web-сессии DeepSeek.
